# JSR（Jiangtherapee Super Resolution）评估：是否“World Best”，能否接入本管线

- 日期：2026-11-01

- 关联论文：《JSR：面向高动态与伪影抑制的局部强度尺度等变 RAW Burst 超分辨率系统》
- 评估依据：仓库 README 与配图、`Core-Only-Source-Code/` 源码与权重（本地克隆后阅读并统计参数）、Releases 信息、公开检索

## 0. 结论

1. **“World Best”没有证据支撑，目前只是项目名。**
   - 论文**尚未发布**：README 写“将在本仓库提供”，arXiv / Zenodo 都检索不到；作者在 Zenodo 上只有一篇关于输出位深的预印本，和超分无关。
   - JSR **没有在任何公开基准**（SyntheticBurst、BurstSR、RealBSR）上报告 PSNR / SSIM / LPIPS。README 自己也说明各实验结果“不合并为总体 PSNR 排名”。
   - 现有对比大多是作者自建的**无噪声合成**实验，给了 JSR **精确运动场**，其中多数对手用自身对齐；而且被比较的模型都是在别的数据和倍率上训练的，属于域外使用。
   - 作为对照，公开基准上 BurstSR（real）当前最好成绩是 BSRT-L + BurstGP 的 30.99 dB（sRGB），JSR 不在任何榜单上。
2. **它有真实的技术亮点，值得借鉴思路**：
   - 局部强度尺度等变：输出亮度与输入严格成比例，暗部提亮后不偏色、不出现固定偏移。
   - 按颜色和亚像素相位累积统计（Tap）。
   - 显式的色差（LCA）几何补偿。
   - 按帧数（K）预测质量和“再多拍一帧的收益”。
   这些设计和本管线“前端输出线性 RAW、后端负责风格”的分层很契合。
3. **不能直接接入本管线，也不适合替代现有模块**，原因有四个，任何一个单独成立都足以否决：
   - **许可证**：仓库没有 LICENSE，默认保留所有权利，代码和权重都不能合法地集成或再分发。
   - **不完整**：公开的只有两个网络的推理代码和权重；对齐、Tap 统计累积、LCA 补偿、质量预测都只在 Windows EXE 里，无法复现完整流程。
   - **算力**：每个输出像素约 470 万次浮点运算。按我的估算，在本机 CPU 上超广角 2 倍超分要约 20 分钟，主摄约 40 分钟，而现在整条管线只要 1.5 到 2.4 秒。
   - **适配性**：
     - 对齐只用全局单应加低阶多项式，不处理运动物体。
     - 当前公开版本的噪声特征通道恒为 0。
     - 实验都是 14-bit 相机的无噪声数据；本机是 10-bit、像素合并、阴影很重的手机传感器。
     - 只支持 2 倍输出，最多 14 帧。
4. **建议**：
   - 用作**离线画质参照**：把手机连拍导出成 DNG，在 Windows 上跑 JSR EXE，和本管线对比。
   - **思路借鉴**：参照公开描述重新实现，不复制代码，见第 4 节。
   - **管线内的超分模块仍按原计划走非学习式方案**：移植 Super Res Zoom 的开源复现（Jamy-L，IPOL 2023）。

## 2. 技术架构（根据 README 和公开源码）

![JSR 数据流（引自仓库 README）](https://raw.githubusercontent.com/y-g-jiang/Jiangtherapee-Super-Resolution-World-Best/main/assets/readme/system-data-flow.png)

1. **配准**：先用全局单应 \(H_k\) 解释主要运动，再拟合最高四次的二维多项式残差场 \(r_k\)；控制点不足时降阶。这本质上是**全局参数化运动**，适合静物、建筑、手持轻微抖动，**不处理局部运动物体**。
2. **Tap 统计**：对齐后的 RAW 样本按颜色和亚像素相位（4×4）累积计数 \(N\)、一阶和 \(S\)、二阶和 \(Q\)，得到 144 个通道（3 色 × 48），同时生成传统融合的 legacy RGB \(L_0\)。
3. **Controller**：输入 151 通道特征（144 Tap + 3 legacy RGB + 3 结构张量 + 1 噪声）。先按局部幅度 \(a_C\) 的 0、1、2 次方归一化，再由 U-Net 输出 36 通道的线性 Tap 权重 \(M_\theta\)，生成 learned RGB。
4. **共享 LCA**：对 learned RGB 和 legacy RGB 施加相同的逐通道几何变换。
5. **RefineNet**：在幅度归一化后的 6 通道输入（两路 RGB）上，以 G 通道为引导做 FiLM 调制，预测“G 残差 + 色差残差”，最后乘回局部幅度 \(a_R\)。
6. **尺度等变性质**：在对应关系和 LCA 固定、黑电平正确、无削波的条件下，\(F(cX) = cF(X)\)。这保证暗部提亮后不会出现与亮度无关的偏色。这是 JSR 最核心、也最站得住的贡献。

### 2.1 网络规模（本地统计）

| 网络 | 结构 | 参数量 | 每输出像素乘加数（估算） |
|---|---|---|---|
| Controller | U-Net，3 级，通道 32/64/128，中间层 256，输入 151 通道，输出 36 通道 | 1.99 M | 约 0.21 M |
| RefineNet | 116 通道，8 个残差块（每块 2 个 3×3 卷积 + G 引导 FiLM），全程在输出分辨率上运行 | 2.17 M | 约 2.16 M |
| 合计 | | 4.16 M | **约 2.37 M 乘加 ≈ 4.7 MFLOP** |

另外两点：

- 1 到 14 帧各有一套 Controller 权重；RefineNet 在 8 到 14 帧之间共用 K14 的权重。
- `local_v7_frontend.py` 中**噪声特征通道（第 150 通道）恒为 0**（`feature[150].fill(0.0)`）。也就是说，公开版本的网络并不显式感知噪声水平。

## 3. “World Best”主张的审视

### 3.1 缺少公认基准

连拍超分领域公认的评测是 SyntheticBurst、BurstSR（real）和 RealBSR，指标是 PSNR / SSIM / LPIPS。截至 2026 年的公开结果：

| 方法 | BurstSR real ×4，sRGB PSNR | 来源 |
|---|---|---|
| BSRT-L + BurstGP | 30.99 dB | BurstGP，arXiv 2604.23508 |
| BSRT-L | 30.59 dB | 同上 |
| BurstM | 30.31 dB | 同上（BurstM 原文中线性域 49.12 dB） |
| DBSR | 29.88 dB | 同上 |
| **JSR** | **未报告** | — |

没有这些基准成绩，就无法和领域内的任何方法做公平的整体比较。

### 3.2 自建实验的局限

| 实验 | 问题 |
|---|---|
| 辐射响应（阶梯环靶）：非线性残差 0.223 DN，是次优 DBSR 的 1/164.6 | 测的正是 JSR**按设计保证**的尺度等变性质，对它天然有利。同一张表里，JSR 的全局斜率是 1.0368，保留增益误差的恒等响应 RMSE 为 158.5 DN，比被强调的 0.223 DN 大约 700 倍。 |
| 色差下的栅格、彩色条纹 | 观测**无噪声**；JSR 和 BurstM 拿到**精确运动场**，其余模型用自身对齐。作者也承认 JSR 会衰减部分真实色度幅度。 |
| 15 种像差：10 个第一、5 个第二 | **单一场景**，六个模型默认对齐，对手都是在其它数据、按 4 倍训练的模型。 |
| 暗部提亮九档 | 提亮九档反映的是线性和偏色控制，作者也注明这“不表示传感器动态范围增加九档”。 |
| “仅需四张”实拍图 | 对照的是**单帧原图**，不是其它多帧方法；属于作者自选的截图。 |
| 逐 K 质量预测 | 条件是固定光学、无噪声、精确平移，属于受控实验。 |

此外，对比里**没有非学习式的手持多帧超分**（Wronski 2019 / Jamy-L IPOL 2023，也就是 Pixel Super Res Zoom 一系）。在手机场景下，这类方法才是最直接的参照。

### 3.3 结论

JSR 在**线性 / HDR 友好**和**抑制周期伪影**这两个特定维度上，提供了有说服力的设计和受控实验。但“World Best”作为整体主张：

- 没有同行评审，论文未公开；
- 没有公认基准成绩；
- 对比条件不对等；
- 无法独立复现（核心前端闭源）。

**评估结论：目前不能认定为“世界最佳”，应视为一个有特色、待验证的个人项目。**

## 4. 能否接入本管线

### 4.1 从功能上看，JSR 对应哪些模块

JSR 的输入是扣黑后的 RAW 连拍，输出是 2 倍分辨率、白平衡之前的线性 RGB。在本管线中，它相当于把下面几个模块合成一块：

| 本管线模块 | JSR 是否覆盖 |
|---|---|
| 金字塔块对齐（`align.cpp`） | 覆盖，但改成全局单应 + 多项式（闭源） |
| 噪声标定 + 鲁棒合并（`merge.cpp`） | 覆盖（Tap 统计 + Controller），但公开版本不感知噪声 |
| 去马赛克（MHC） | 覆盖（RefineNet 直接输出 RGB） |
| 色度降噪 | 部分覆盖（合并过程隐含降噪） |
| 2 倍超分（路线图 P2） | 覆盖 |
| LSC / WB / CCM / 色调映射 / 锐化 / 输出 | 不覆盖，仍由本管线后端负责 |

### 4.2 阻碍

| 维度 | 评估 |
|---|---|
| 法律 | **无许可证**，默认保留所有权利。代码和权重都不能集成或分发。这一条直接否决“代码级接入”。 |
| 完整性 | 只公开了两个网络；对齐、Tap 累积、legacy RGB、LCA 都在 EXE 里，自行补齐等于重写，而且权重与这些闭源前端的统计定义强耦合，补不准就用不了权重。 |
| 算力 | 每输出像素约 4.7 MFLOP。本机 CPU（1×X2 + 3×A710 + 4×A510）FP32 实际可达约 100 GFLOPS 量级（估算）：超广角 8MP 输入 2 倍输出 32 MP，约 1.5×10¹⁴ FLOP，约 20 分钟；主摄 16MP 输入 2 倍输出 64 MP，约 40 分钟。1 倍输出也要约 5 到 10 分钟。本管线现在全程 1.5 到 2.4 秒。即使换到 Adreno 725 GPU，估计仍需数分钟。 |
| 内存 | Controller 输入 151 通道 FP32：64 MP 时约 38 GB，必须分块；RefineNet 中间层 116 通道。 |
| 运动 | 全局参数化运动模型，场景里的人、车、树叶等局部运动无法处理。手机手持场景常见，而 HDR+ 系的局部块对齐 + 鲁棒合并专门处理这类情况。 |
| 传感器域 | 实验数据是 14-bit 相机（Panasonic S5M2）。本机是 10-bit、四合一像素合并、角落阴影增益约 5 倍、高 ISO 噪声大。公开版本噪声通道恒为 0，在本机高 ISO 素材上的表现未知。 |
| 规格 | 固定 2 倍输出，最多 14 帧；本机计划支持到 32 帧。 |

**结论：不能接入，也不能替代任何现有模块。**

### 4.3 可行且有价值的用法

1. **离线画质参照**（成本低，推荐）：
   - 用探针 App 的 `DngCreator` 导出每帧 DNG（`MainActivity` 已有单帧 DNG 能力，扩展到连拍即可）。
   - 在 Windows 机器上用 JSR EXE 处理，与本管线 1 倍或 2 倍结果对比。
   - 用途：看静态场景下超分细节能做到什么程度，作为本管线 P2 超分模块的目标参照。
2. **参照公开描述独立实现（不复制代码）**：

| 可借鉴的思路 | 落到本管线的方式 |
|---|---|
| 局部强度尺度等变 | 将来若引入任何学习式模块（降噪、AWB、风格），都先除以局部幅度、处理后再乘回，保证暗部提亮不偏色。 |
| 按颜色和亚像素相位累积统计 | 与 Super Res Zoom 的核回归累积同源；做超分时按相位记录样本数，用来判断哪些区域真的有超分信息。 |
| 显式 LCA 补偿 | 超广角边缘色差明显。可以在合并后、去马赛克前按通道做径向缩放校正（参数离线标定）。 |
| 逐 K 质量预测 | 本机每次开机最多 65 个 RAW 请求。可根据已拍帧的亚像素相位覆盖率和噪声，决定是否停止连拍，节省请求数和时间。 |
| 阶梯环靶的辐射响应测试 | 加入本管线的回归测试，检查合并 + 色调映射前的线性度。 |

3. **管线内超分的推荐路线（不变）**：
   - 移植 [Handheld Multi-Frame Super-Resolution（Jamy-L，IPOL 2023）](https://github.com/Jamy-L/Handheld-Multi-Frame-Super-Resolution)：Super Res Zoom 的开源复现，非学习式。它直接替代“合并 + 去马赛克”，并且自带鲁棒性处理局部运动。许可证需另行核对。
   - 计算量是每像素几百次运算的量级，比 JSR 低四个数量级，CPU 上可以做到秒级。
   - 需要先把对齐升级为亚像素精度（在现有块对齐基础上加 Lucas-Kanade 精修）。
